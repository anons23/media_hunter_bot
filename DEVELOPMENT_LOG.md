## 1. Текущий статус проекта

**Проект:** Telegram-бот Media Hunter.

**Основной стек:** Python, aiogram 3.x, yt-dlp, ffmpeg, SQLite, Telegram Bot API.

**Основная функция:** скачивание/обработка медиа, уникализация, водяные знаки, отправка пользователю, автопостинг, Premium, ОПП и административные функции.

**Цель текущей ветки:** довести security-вариант до состояния, пригодного для запуска на сервере, исправляя только реальные баги/риски без ненужной перестройки архитектуры.

**Ограничения окружения:**
- VPS с маленьким диском (~9.8 GB).
- Лимит Telegram Bot API: ориентироваться на максимум около 2 GB.
- Производственный лимит входного файла Media Hunter: **1024 MB**.
- Не увеличивать лимиты только ради рекомендаций аудита — учитывать фактические ограничения сервера.
